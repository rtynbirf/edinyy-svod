# ПАКЕТ ДОКУМЕНТАЦИИ: АРХИТЕКТУРНЫЙ РЕГЛАМЕНТ
## Полимат-Агент PID1 (LFS Kernel) & PID0 Environment

---

### 1. КОМПОНЕНТНАЯ СТРУКТУРА ПАКЕТА

Пакет содержит 3 поколения эволюции ядра и дашбордов, а также полный комплект нормативной документации:

#### А. Python-Ядра (Back-End Logic):
1. `polymath_agent_prototype.py` (v1): Первичное LFS-ядро. Базовое динамическое выравнивание вектора.
2. `polymath_agent_prototype-v2.py` (v2): Мультиагентный оркестратор. Параллельный диалектический синтез векторов конфликта.
3. `polymath_agent_prototype-v3.py` (v3): Итоговый 6-слойный стек с PID-контроллером обратной связи и антигаллюцинаторным фильтром.

#### Б. Visual HTML Dashboards (Front-End Interface):
1. `polymath_agent_dashboard.html` (v1): Базовая визуализация моста и скаляров энтропии.
2. `polymath_agent_dashboard-v2.html` (v2): Мультиагентная панель управления с графиками выравнивания и регуляторами напряженности.
3. `polymath_agent_dashboard-v3.html` (v3): Полный интерактивный дашборд с мониторингом P-I-D коэффициентов, StateGraph и симулятором внешнего стресса.

#### В. Спецификации и Документация:
1. `TECHNICAL_SPECIFICATION.md`: Техническое Задание.
2. `ROADMAP.md`: Дорожная карта проектов Эпох I–IV.
3. `ARCHITECTURE_OVERVIEW.md`: Данный документ.
4. `README.md`: Руководство по быстрой сборке и запуску.

### 2. ПРИНЦИПЫ АНТИГАЛЛЮЦИНАТОРНОЙ БЕЗОПАСНОСТИ

1. **Изоляция Context Window:** Под-агенты не перегружают друг друга диалоговой преисторией. Обмен идет только вычисленными векторами выравнивания.
2. **PID-Фильтр сбоев:** 
   - Интегральный блок ($K_i$) накапливает расхождения и принудительно очищает дрейф контекста при превышении порога.
   - Дифференциальный блок ($K_d$) блокирует действия, вызывающие резкий рост энтропии $dS/dt > 0$.
3. **Guardrail Verifier:** Все выходы синтеза пропадают через проверку не-нулевой суммы: $H_{new} \ge H_{old}$ и $S_{new} < S_{old}$.

### 3. РУКОВОДСТВО ПО ИСПОЛЬЗОВАНИЮ

#### Запуск ядра v3 в консоли:
```bash
python3 polymath_agent_prototype-v3.py
```

#### Открытие визуального дашборда v3:
Откройте файл `polymath_agent_dashboard-v3.html` в любом современном веб-браузере. Вы увидите графики в реальном времени, панель управления под-агентами и кнопки запуска стресс-теста.
