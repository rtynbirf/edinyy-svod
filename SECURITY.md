# Security Policy

Правила аккаунта: `rtynbirf/repo-doctrine` (разделы 03 «Токены и секреты» и
05 «Аварийные процедуры»).

## Reporting a vulnerability

- Приватное сообщение Хозяину через GitHub (private vulnerability reporting
  включён для этого репозитория) — не через public issue.
- Утёкший токен не публикуется ни в issue, ни в PR, ни в скриншоте: доктрина 03,
  «засветился — ротация».

## Что считать уязвимостью здесь

- Появление внешних запросов в артефакте (контракт жанра: ноль внешних запросов).
- Расхождение пломб: `sha256sum -c SHA256SUMS.txt` не сходится.
- Расхождение каталога (раздел II) с живым GitHub API без пометки в комментарии.
- Токен или секрет в любом файле репозитория.
