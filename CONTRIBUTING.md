# Contributing

Правила аккаунта — `rtynbirf/repo-doctrine` (раздел 04 «Конвенции агентов»).

## Как вносить изменения

1. **Аддитивность.** Добавлять файлы и главы можно; удалять и переписывать
   чужое — нельзя. Спорные зоны решает Хозяин.
2. **Один смысл — один коммит.** Формат: `тип(область): суть по-русски`.
   Типы: `feat`, `fix`, `docs`, `chore`, `refactor`, `test`, `worklog`.
3. **Артефакт собирается, не правится.** Тексты — в `build/svod_content.py`,
   данные — в `build/catalog_data.py`; после правки `python3 build/build_svod.py`
   и обновление пломб. Ручные правки HTML запрещены.
4. **Проверяй то, что отдаёшь.** Сборщик сам прогоняет 6 проверок и падает при
   провале; после сборки файл открывается заново, вердикт печатается.
5. **Секреты вне слежки.** Токены — в файлах вне git (`.gitignore` содержит
   `scripts/.tok*`, `.env`); в чате токен считается скомпрометированным.
6. **Незавершённость = провал.** Раздел «TODO» в отданном файле не допустим.
